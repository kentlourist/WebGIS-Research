🌍 Cara Menampilkan Data Spasial dari GEE

Karena WebGIS ini dihosting di GitHub Pages (static), data GEE harus diambil melalui salah satu dari dua cara berikut:

  1. Via GEE Code Editor (Tile URL):
    Di akhir script GEE Anda, tambahkan:
    var url = namaLayer.getMap(visParams).urlFormat;
    print('URL:', url);
    Lalu salin URL dari Console dan paste di tab "GEE URL" pada panel kanan.
  2. Via GEE Apps (Rekomendasi):
    Publish script Anda sebagai Earth Engine App, lalu embed URL-nya. Cara ini tidak perlu menyalin URL setiap sesi.
  3. Export ke GeoJSON / COG:
    Export hasil analisis GEE ke Google Drive sebagai GeoJSON, lalu upload langsung via fitur "Upload Area Kajian" di sidebar kiri.
